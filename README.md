# Calculating the Hypotenuse of a Right Triangle Using the Math
## Description
This program will help give you the **hypotenuse** of a right triangle by getting the 2 lengths of the shorter sides *(a, b)*, compute it by using the **Pythagorean Theorem**, and using *functions* from the `math` library. 
## How to Run
1. Open the program file by clicking on the `.py` file.

2. Run the program.

3. Enter the values for a and b. 

4. Check the hypotenuse of the right triangle displayed on the screen.
## Input Needed
- a
- b
## Sample Output
Enter the length of the side a: 3

Enter the length of the side b: 4

The distance of the two lengths are: 5.00
